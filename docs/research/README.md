# Research guide

本專案研究無人機教育桌遊、人工智慧路徑演算法教學，以及學習過程中的認知負荷與心流狀態。計畫與教學設計位於 `docs/`，原始紀錄與題庫位於 `data/`，分析與成果位於 `reports/`，論文與文獻位於 `papers/`。

## 閱讀順序

| 階段 | 入口 | 內容 |
| --- | --- | --- |
| 計畫與申請 | [Planning](planning/README.md) | 原始計畫、修訂資料、申請表件與參考專題，10 個來源檔案。 |
| 教學執行 | [Teaching](../teaching/README.md) | 活動流程、課程申請、計畫參照與文件題庫；活動 JSON 在 `data/`。 |
| 資料與分析 | [Data](../../data/README.md) · [Analysis](../../reports/analysis/README.md) | 答題紀錄、前測與後測報告。 |
| 研究成果 | [Reports](../../reports/README.md) · [TANET papers](../../papers/README.md) | 成果報告初稿、論文原稿與修訂稿。 |
| 文獻與寫作 | [References](../../papers/references/README.md) · [Templates](../templates/README.md) | 六篇主題文獻與成果報告、學位論文範本。 |

## 版本與來源

- [File index](../archive/file-index.md)：全部 36 個來源檔案的入口與原始來源。
- [Versions](../archive/versions.md)：版本、格式配對與同內容來源副本。
- [Research manifest](../archive/research-files.json)：現行路徑、大小、SHA-256 及原始資料狀態。
