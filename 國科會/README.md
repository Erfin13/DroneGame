# 國科會研究資料

本資料集涵蓋無人機教育桌遊、人工智慧路徑演算法教學、活動教材、問卷與答題紀錄，以及研究成果與參考文獻。36 個原始檔案依研究工作流程重新編排，原始檔名、內容、不同格式與來源副本均保留。

## 建議閱讀順序

1. 閱讀「計畫與申請」的原始研究計畫與修訂資料，了解研究問題與桌遊設計。
2. 閱讀「活動與教材」的桌遊流程與題庫，了解活動如何執行。
3. 依前測、後測、答題紀錄的順序查看「資料與分析」。
4. 查看「研究成果」的成果報告初稿與 TANET 修訂稿，原稿並列留存。
5. 依研究主題查閱「參考文獻」，撰寫時使用「寫作範本」。
