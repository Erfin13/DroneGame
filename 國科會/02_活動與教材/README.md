## 題庫使用

`題目.json` 為 297 題的根層級題庫，各難度 99 題；格式與遊戲的根節點讀取方式對應。獨立的 20 題範例位於儲存庫 `data/question-banks/`，其外層 `questions` 包裝需先區分。詳見 [資料格式說明](../../docs/data-formats.md)。
